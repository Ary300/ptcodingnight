# Editor parity fixtures

`java.json` is an answer key for the problem editor's Java mode, written against IntelliJ IDEA with the default keymap and the default Java code style (4-space indent, 8-space continuation indent, line comments at column 0 with no added space). Each case gives the editor text before, the keys pressed, and the text after, with the caret written as `|` and a selection as `[...]`; a string that contains `|` has no selection, so any brackets in it are Java code. Every case was checked against IntelliJ IDEA's documented default behaviour for that action, and anything that changes with a setting or could not be pinned down with confidence was left out. Two gaps are deliberate. Typing `{` inside a code block is absent because IntelliJ adds the `}` when Enter is pressed after it, and Enter between an empty `()` is absent because where the `)` lands depends on code-style options. The Enter-after-unmatched-brace and continuation-indent cases cover the dependable part of each.
