# Editor parity fixtures

`python.json` is an answer key for the contest editor's Python mode. Each case gives the text before, the keys pressed and the text after, with the caret written as `|` and a selection as `[...]`. It covers paired brackets and quotes, Backspace on an empty pair, indentation on Enter, the absence of dedent while typing, `#` comment toggling, duplicate line, move line, the `main` live template and completion of builtins and `math.`, `collections.` and `heapq.` members. Each case was checked against PyCharm (default keymap, 4 spaces)'s documented default behaviour, and anything whose result depends on a setting or could not be pinned down was left out. One example is what PyCharm does to the indent of `else` once its colon is typed.
