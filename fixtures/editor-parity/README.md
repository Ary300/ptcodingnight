# Editor parity fixtures

`cpp.json` is the answer key for the contest editor's C++ mode. It holds 97 cases, each a `before` text, the keys a student presses, and the `after` text that CLion (default keymap, 4 spaces) produces, with the caret written as `|` and a selection written as `[...]`. The cases cover bracket and quote pairing, `}` snapping to its block, Enter inside `{}`, `//` comment toggling, duplicate line, move line, Backspace on empty pairs, and completion after `std::` and on container members, in the shape of stdin/stdout programs a high-school student writes. Each case was checked against CLion (default keymap, 4 spaces)'s documented default behaviour, and anything that depends on a setting or could not be confirmed was left out. That is why there are no live-template cases and no Enter-inside-`()` case yet: CLion's exact template bodies and its continuation indent for a split argument list were not certain enough to pin. Completion cases name the popup item by its bare identifier (`Accept:push_back`), and they assume CLion's rule that a function with parameters leaves the caret inside `()` while a function with none leaves it after them.
